# Live Clock

A clean, responsive browser clock that displays the current local time and date in a distraction-free full-screen layout.

**Live demo:** [yamentou.github.io/live.clock](https://yamentou.github.io/live.clock/)

## Features

- Displays the current local time with seconds
- Switches between 12-hour and 24-hour formats
- Shows or hides the current date
- Light and dark themes
- Optional full-screen mode
- Hideable controls for a minimal clock display
- Responsive sizing for desktop, tablet, and mobile screens
- No vertical or horizontal scrollbars

## Remembered Settings

The clock automatically remembers your selected format, theme, date visibility, and controls visibility in the browser. These preferences are kept for up to one year and require no account or setup.

Preferences are stored locally in the browser, so they are specific to the browser and device where you use the clock.

## Run Locally

Open `index.html` directly in a browser, or serve the project from any static web server.
